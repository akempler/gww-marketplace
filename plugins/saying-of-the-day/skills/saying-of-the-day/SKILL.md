# Saying of the Day

Generate an original, pithy saying of the day.

## Instructions

1. Compose one original saying that is:
   - Brief — one or two sentences max
   - Witty, insightful, or cleverly worded
   - Original — not a known quote or cliche
   - Memorable enough to stick with someone all day
2. Present the saying on its own line, formatted in italics.
3. Follow it with a one-sentence reflection on what it means or when it applies.
4. If the user provides a topic via `$ARGUMENTS`, tailor the saying to that theme.

## Arguments

Optional topic: $ARGUMENTS

## Example

If the user runs `/saying-of-the-day:saying-of-the-day`, respond with something like:

*The best shortcut is the one you never need to take twice.*

When you invest time doing something right the first time, you save yourself from the detour of fixing it later.
